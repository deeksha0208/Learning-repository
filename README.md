    <h1>Week 1: Fundamentals of Git and GitHub</h1>

    <h2>1. Overview of Git</h2>
    <p>
        Git is an open-source version control system that helps developers
        record changes in source code and project files. It allows users to
        maintain different versions of a project, identify previous changes,
        and work on software development tasks efficiently.
    </p>

    <h2>2. Overview of GitHub</h2>
    <p>
        GitHub is an online platform that allows developers to store their
        Git repositories on the internet. It provides facilities to share
        code, collaborate with team members, and manage software projects
        from different locations.
    </p>

    <h2>3. Fundamental Concepts</h2>
    <ul>
        <li><b>Repository:</b> A storage location containing project files and their history.</li>
        <li><b>Commit:</b> A saved record of changes made to a project.</li>
        <li><b>Branch:</b> An independent version of a project used for development.</li>
        <li><b>Merge:</b> Combining changes from one branch into another.</li>
        <li><b>Working Directory:</b> The folder where project files are created and modified.</li>
        <li><b>Staging Area:</b> The area where changes are prepared before committing.</li>
        <li><b>Remote Repository:</b> A repository maintained on an online server.</li>
    </ul>

    <h2>4. Comparison Between Git and GitHub</h2>
    <p>
        Git is a tool that tracks changes in files and maintains project
        versions. GitHub is an online service that hosts Git repositories
        and supports sharing and collaboration. Git can be used locally
        without GitHub, while GitHub provides online access to repositories.
    </p>

    <h2>5. Common Git Commands</h2>
    <ul>
        <li><b>git init:</b> Creates a new Git repository.</li>
        <li><b>git status:</b> Displays the current state of project files.</li>
        <li><b>git add .:</b> Stages changes for the next commit.</li>
        <li><b>git commit -m "message":</b> Saves staged changes with a message.</li>
        <li><b>git log:</b> Shows the history of commits.</li>
        <li><b>git clone URL:</b> Copies a remote repository to the local computer.</li>
        <li><b>git push:</b> Uploads local commits to a remote repository.</li>
        <li><b>git pull:</b> Retrieves and integrates changes from a remote repository.</li>
    </ul>

    <h2>6. Git Project Management Process</h2>
    <ol>
        <li>Create a project and add the required files.</li>
        <li>Initialize Git to start tracking the project.</li>
        <li>Modify files according to project requirements.</li>
        <li>Stage the required changes using the git add command.</li>
        <li>Record the changes using the git commit command.</li>
        <li>Upload the commits to GitHub using the git push command.</li>
    </ol>

    <h2>7. Learning Summary</h2>
    <p>
        I gained knowledge about the role of version control in software
        development and understood how Git and GitHub work together.
        I learned the purpose of repositories, branches, commits, and
        staging areas, along with essential commands for managing project
        versions and sharing code online.
    </p>
