Week 2: Introduction to JavaScript

1. Introduction to JavaScript

JavaScript is a programming language used to make websites interactive and dynamic. It allows developers to respond to user actions, validate forms, update webpage content, and perform calculations. JavaScript works together with HTML and CSS to create interactive web applications.

2. Importance of JavaScript

JavaScript plays an important role in modern web development. It helps websites respond to user input without requiring the entire page to reload. It is also used in web applications, server-side development, games, and mobile applications.

3. Basic Concepts of JavaScript

  • Variables: Used to store data. JavaScript provides var, let, and const for declaring variables.
  • Data Types: Define the kind of value stored, such as strings, numbers, booleans, arrays, and objects.
  • Operators: Used to perform arithmetic, comparison, assignment, and logical operations.
  • Conditional Statements: Used to make decisions based on conditions using if, else, and switch.
  • Loops: Used to execute a block of code repeatedly. Examples include for, while, and do...while.
  • Functions: Reusable blocks of code designed to perform specific tasks.
  • Arrays: Used to store multiple values in a single variable.
  • Objects: Used to organize related information using properties and values.

4. JavaScript Variables and Data Types

Variables store information that can be used throughout a program. The let keyword is used for variables that may change, while const is used for bindings that should not be reassigned.

Example:

let name = "Deeksha";
let age = 20;
const course = "CSE";

console.log(name);
console.log(age);
console.log(course);

In this example, name and course contain string values, while age contains a numeric value. The console.log() method displays the values in the browser console.

5. Operators and Conditional Statements

Operators help perform calculations and compare values. Conditional statements allow a program to execute different instructions depending on whether a condition is true or false.

Example:

let marks = 75;

if (marks >= 35) {
    console.log("Pass");
} else {
    console.log("Fail");
}

Here, the program checks whether the marks are at least 35. If the condition is true, it displays "Pass"; otherwise, it displays "Fail".

6. Functions and Events in JavaScript

A function is a reusable block of code that performs a particular task. Events occur when users interact with a webpage, such as clicking a button, typing text, or submitting a form. JavaScript can execute functions in response to events.

Example:

function greet() {
    alert("Welcome to JavaScript!");
}

The greet() function displays a welcome message when it is called. It can be connected to a button click using an appropriate event handler.

7. JavaScript and HTML Integration

JavaScript can be included directly inside an HTML document using the script tag or linked through an external JavaScript file. It can access HTML elements and modify their content, attributes, and styles.

Example:

<h2 id="message">Hello</h2>

<script>
document.getElementById("message").textContent =
    "Welcome to my webpage!";
</script>

In this example, JavaScript selects the HTML element with the ID message and changes its displayed text.

8. Applications of JavaScript

  • Creating interactive websites.
  • Validating user input in forms.
  • Updating webpage content dynamically.
  • Developing browser-based games.
  • Communicating with web APIs.
  • Building server-side applications using Node.js.

9. What I Learned

I learned the fundamentals of JavaScript and its importance in web development. I understood variables, data types, operators, conditional statements, loops, functions, and events. I also learned how JavaScript interacts with HTML elements to make webpages more interactive and useful.
